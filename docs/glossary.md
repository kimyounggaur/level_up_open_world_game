# 용어집

| 용어 | 뜻 |
|---|---|
| 과제 | 판정 조건이 있는 음악 활동 하나. 기존 문서의 퀘스트 |
| 판본 | 같은 과제의 다른 예시나 난도. 모든 판본은 처음부터 고를 수 있다 |
| 설치물 | 월드 안에 놓인 장치. 음이나 쉼을 놓고 들을 수 있다 |
| 정거장 | 설치물이나 작업대가 있는 장소 하나. 지도와 목록에 처음부터 표시된다 |
| 작업대 | 마을 건물. 들어가면 패널이 열린다 |
| 패널 | 화면 위에 뜨는 편집 화면. 모든 과제는 패널로도 풀 수 있다 |
| 자리 | 설치물에서 재료를 놓는 칸 |
| 재료 | 놓을 수 있는 음, 쉼, 종, 이름표 |
| 초안 | 사용자가 편집 중인 배치 |
| 세계 반응 | 사용자의 활동으로 세계의 소리와 모습이 바뀌는 것 |
| 월드 px | 월드 좌표의 단위. 화면 px와 다르다 |
| 틱 | 시간의 내부 단위. 4분음표 = 960틱 |
| 음급 | 12음 가운데 하나(C=0 … B=11). 옥타브를 무시한 음높이 종류 |
| 기보 음 | 사용자가 적은 음이름(letter, accidental, octave). 소리 높이(MIDI)와 따로 저장한다 |
| 해석 음 | 조표와 임시표를 적용해 확정한 음(resolvedPitch) |
| SlotMap | 설치물의 '몇 번째 자리'를 음악 데이터로 바꾸는 변환표. 화면 좌표는 판정기로 넘어가지 않는다 |
| 다녀감·해냄·만듦 | 세계에 남는 세 가지 흔적(6.1) |
| 합주 층수 | 여섯 지역의 소리 층을 더한 수(0–18) |
