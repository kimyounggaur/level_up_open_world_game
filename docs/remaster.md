# 제공 에셋 적용: 프로타주 리마스터

적용일: 2026-11-19 (한국 시간). 기준 저장소: [level_up_open_world_game](https://github.com/kimyounggaur/level_up_open_world_game), 원화 기준 커밋 `b20fc29372b1f5556c8ff551f3c0198f28f5e7cb`.

사용자가 첨부한 캐릭터 시트와 환경 에셋을 게임의 실제 렌더링에 연결했다. 새 이미지 생성이나 원화 재디자인 없이 원본의 색·복장·건물 형태·질감을 사용한다. 음악 학습 과제, 정답, 저장 형식, 정거장 위치 및 이동 충돌 격자는 변경하지 않는다.

## 원본과 런타임의 관계

| 제공 ZIP | 적용 방식 | 런타임 위치 |
| --- | --- | --- |
| `LevelUp_Character_Sheets_20261118.zip` | PNG 시트 8장에서 전신·방향별 모습·초상화 추출, 외곽에 연결된 종이 바탕 제거, 투명 WebP 아틀라스 준비 | `public/assets/remaster/characters/` |
| `LevelUp_Frottage_Runtime_v1_20261118(웹 최적화 Web).zip` | WebP 29장과 SVG 8장 및 원본 manifest를 바이트 변경 없이 복사 | `public/assets/remaster/frottage/` |
| `LevelUp_Frottage_Remaster_v1_20261118.zip` | PNG 마스터와 제작 자료 확인에 사용. 웹 최적화 ZIP과 중복되는 고용량 PNG를 다시 배포하지 않음 | 원본 첨부 보존 |

환경 런타임 파일 37종의 SHA-256을 원본 `asset_manifest.json`과 대조했다. 이 manifest의 `proposal`·`not integrated` 문구는 제공 당시의 기록이다. 원본 기록을 수정하지 않았으며 실제 연결 내역은 이 문서와 코드에 기록한다. 캐릭터 PNG 원본 해시와 추출 사각형은 캐릭터 폴더의 `manifest.json`에 있다.

대용량 원화 13장은 저장소 전송을 위해 `asset-source/remaster-parts/`에 작은 바이너리 조각으로 보관한다. `npm ci`의 `postinstall`이 조각을 합치고 길이와 SHA-256을 검사한 뒤 원래 `public/` 경로에 복원한다. 압축 품질·크기·픽셀은 바뀌지 않는다. 검증과 빌드는 복원이 끝난 원본을 사용한다. 원화를 교체할 때는 해당 조각·복원 manifest·원본 에셋 manifest를 함께 갱신해야 한다.

원본 캐릭터 SVG는 전체 콘셉트 시트를 벡터로 추적한 파일이다. 신체 리깅이나 애니메이션 파일이 아니므로 브라우저에는 투명 WebP 추출본을 사용한다. 원본 SVG와 PNG를 변형하거나 덮어쓰지 않는다.

`src/world/remaster.ts`는 환경 에셋의 배치와 원본 알파 바운드 정렬을 관리한다. `remasterAssets.json`은 원화의 불투명 영역과 크기를 보관한다. 이미지 비율을 유지한 채 기존 건물·소품 크기에 맞춘다. 모든 외부 이미지 요청은 없으며 앱과 같은 출처에서 파일을 불러온다.

렌더러는 Phaser의 자동 선택을 사용한다. WebGL을 사용할 수 있는 환경은 WebGL로, 그래픽 컨텍스트가 제공되지 않는 환경은 Canvas로 표시한다. 환경 이미지의 위치·학습 판정·조작은 동일하다.

## 재현

캐릭터 원본 ZIP을 풀고 아래 명령에 실제 폴더 경로를 전달한다.

```sh
node tools/prepare-characters.mjs /absolute/path/to/LevelUp_Character_Sheets_20261118
npm run build:world
npm run validate
npm run check:world
npm run typecheck
npm test
npm run build
```

환경 소재는 굽기 전에 원본 해시를 검증한다. 소재 연구 이미지의 반복 연결은 원래 무봉제로 검증되지 않았으므로 굽기에서 가장자리 반사 패턴을 사용하여 급격한 이음을 줄인다. 게임 실행 중에 거대한 소재 파일을 프레임마다 합성하지 않는다.

## 표현의 범위

캐릭터 시트는 연속 걷기 원화가 아니다. 아틀라스의 기존 `idle`·`walk` 프레임 이름은 각 방향의 같은 추출 그림을 재사용한다. 게임의 작은 상하 이동으로 걸음을 표현하며 움직임 줄이기 설정에서는 흔들지 않는다. 새 애니메이션 원화를 만들었다고 표시하지 않는다.

학습 기호와 판정 정보는 정확성이 필요한 기존 코드·텍스트 층을 사용한다. 장식 그림의 빈 판·외관을 학습 정답의 근거로 사용하지 않는다. 원본의 전경·안내 카드 풍경은 2D 월드의 좌표·충돌 격자를 대체하지 않는다.

## 배포 유지보수

`vercel.json`의 `/assets/(.*)`는 장기 immutable 캐시를 사용한다. 이번 추가 경로는 기존 배포에 없던 경로이므로 첫 적용과 충돌하지 않는다. 다음에 같은 파일명의 원화를 교체할 때는 디렉터리 버전 또는 파일명을 변경하고 코드 참조를 함께 바꾸어야 한다. `/world/`의 재생성 바닥은 기존 `no-cache` 정책을 따른다.

출처 대장은 `content/sources/asset-ledger.json`의 `img.remaster.frottage`, `img.remaster.characters`에 기록했다. 제공 에셋은 실제 로컬 파일과 출처 항목이 함께 있을 때에만 새 이미지 참조 검사를 통과한다. 외부 URL, 미등록 파일, 없는 파일은 계속 거부한다. 학습 내용 잠금은 수정하지 않는다.
