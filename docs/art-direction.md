# 화풍: 햇살 과슈

작성일 2026-11-14. 결정 D-308(화풍), D-309(아틀라스 압축), D-310(캐릭터 그림), D-311(화면 스킨).

## 왜 바꾸었나

사용자가 2026-11-14에 "게임 UI와 디자인을 업그레이드하기 위해 에셋 작업"을 맡기며 특정 상용 게임의 화풍을 예로 들었다. 그 게임의 그림과 화면 디자인은 그 회사의 것이고, 이 게임은 공개 주소에 올라가 있다. 그래서 그 게임을 닮게 만들지 않고, 비슷한 분위기(손으로 칠한 그림, 탁 트인 모험의 공기)를 가진 **이 게임만의 화풍**을 새로 정했다. 설계서의 W-12(다른 게임의 그림을 쓰지 않는다)도 그대로 지킨다.

- 다른 게임의 이름, 기호, 문양, 화면 요소를 가져오지 않는다. 새 그림의 소재는 아래 '소재와 무늬'에서만 고른다.
- 설계서 9.1의 "외곽선 없는 평면 벡터, 오른쪽 아래로 어긋난 단색 그림자"에서 벗어난다(D-308). 자리와 크기, 색의 뜻(지역색, 캐릭터의 보라, 상호작용의 청록)은 그대로다.

## 원칙

1. **빛**: 해는 왼쪽 위(10시)에 있다. 모든 사물은 밝은 면(왼쪽 위), 그늘 면(오른쪽 아래), 땅에 닿는 짙고 작은 그림자, 오른쪽 아래로 드리운 부드러운 그림자를 가진다.
2. **색**: 밝은 면은 밝게 하고 노란 쪽으로 조금 돌린다. 그늘 면은 어둡게 하고 차가운 쪽으로 돌린다: 초록과 파랑은 푸른 쪽(225°), 노랑과 주황은 붉은 주황 쪽(18°), 빨강과 자주는 자줏빛(330°). 노랑을 푸른 쪽으로 돌리면 색상환의 가까운 길이 초록을 지나 금빛 그늘이 풀빛으로 얼룩진다(`world-src/art/paint.ts`의 `lit`, `shade`).
3. **그림자**: 검정이 아니라 차가운 청록 회색(`#3E5A5C`)에 투명도를 준다. 바깥은 옅고 안은 조금 짙은 두 겹이다.
4. **모양**: 둥글고 두툼한 덩어리. 가장자리는 손으로 그린 듯 조금 일렁인다. 외곽선은 그리지 않고 명암의 차이로 덩어리를 나눈다.
5. **결**: 잎, 풀, 나뭇결, 기와 줄 같은 짧은 붓자국. 결은 구운 그림에만 있고 화면에서 움직이지 않는다.
6. **소재와 무늬**: 악기에서 온 재료와 모양을 쓴다. 밝은 나무(가문비), 짙은 나무(로즈우드), 놋쇠(종, 갓, 못), 청록 칠. 무늬는 손종, 건반, 물결, 디딤돌, 소리 물결 호, 울림구멍 고리. 악보 기호(오선, 음표, 음자리표)는 장식으로 만들지 않는다(설계서 9.4). 풍향계의 높은음자리표와 허수아비의 음표처럼 뜻이 있는 곳에만 정확한 모양으로 둔다.

## 만드는 방식

설계서 9.6처럼 좌표를 적은 코드에서 SVG를 만들어 굽는다.

```
world-src/art/*.ts ──npm run paint:sprites──▶ world-src/sprites/*.svg, public/world/ui-intro-banner.svg
world-src/sprites/*.svg ──npm run build:world──▶ public/world/objects.webp(아틀라스), 바닥 조각 48장
```

| 파일 | 하는 일 |
|---|---|
| `paint.ts` | 도구: 씨앗(같은 그림), 색(`lit`, `shade`, `mix`), 부드러운 곡선과 덩어리, 그라디언트, 그늘 초승달(`crescent`), 땅 그림자 |
| `trees.ts` | 나무 21장. 잎 뭉치를 바깥 고리 → 안쪽 고리 → 꼭대기 순으로 밝게 겹친다 |
| `signs.ts` | 지역 표지판 5장 |
| `landmarks.ts` | 풍향계, 정자, 기준음 탑(A4 판), 메아리 벽 |
| `field.ts` | 허수아비 둘, 가운데 줄 밧줄 |
| `characters.ts` | 주인공 32장(48×72, 4방향 × 서 있기 2 + 걷기 6) |
| `ground.ts` | 바닥: 풀 결 무늬, 부드러운 그림자, 길의 자갈과 풀, 모임지붕, 덤불, 광장 바닥 돌, 무대, 의자 |
| `banner.ts` | 첫 안내 카드의 풍경 띠 |
| `index.ts` | 그림 이름으로 칠하는 코드를 고른다. 모르는 이름의 그림은 손으로 그린 것으로 보고 건드리지 않는다 |

- 손으로 그린 SVG를 넣는 길(6-3)은 그대로다. `world-src/sprites/`에 새 이름으로 넣으면 칠하는 도구가 건드리지 않는다. 칠하는 코드가 아는 이름의 파일을 손으로 고치면 `npm test`(`tests/unit/art-paint.test.ts`)와 `npm run check:paint`가 코드와 다르다고 알린다. 그 그림을 손으로 관리하려면 `world-src/art/index.ts`의 목록에서 빼면 된다.
- 시험이 읽는 자리는 바꾸지 않았다: 표지판의 판 바탕색(`#E9DDB8`, 판 아래쪽)과 윗띠 경로(`M14 19…`)와 그 색, 허수아비 기둥(너비 8의 사각형), 나무 덮개의 반지름(그림 이름의 r, 그 밖에는 칠하지 않음을 시험이 화소로 확인), 그림 틀의 크기, 나무 그림자 원의 자리와 반지름.
- 마을 바닥은 두 방식으로 그릴 수 있다: 게임은 `painted`, 시안 B01과 배치를 픽셀로 대조하는 시험(3-2)은 `mock`(이전과 같은 평면 그림). 자리와 크기는 같은 데이터에서 나온다.

## 캐릭터(D-310)

- 생김새: 보라 베레모(캐릭터에만 쓰는 보라 `#755675`), 연보라 웃옷, 청록 목도리, 등에 멘 우쿨렐레. 이 게임을 위해 새로 지은 모습이다.
- 발은 그림 칸의 (24, 68)이다. 장면은 기준점을 (0.5, 68/72)에 두어 발이 캐릭터의 월드 좌표에 온다. 겹침 순서는 이전처럼 발의 y다.
- 걷기 한 바퀴(두 걸음)는 0.56초, 걷는 동안 그림 전체가 1.2 px 위아래로 움직인다(두 발이 모이는 장에서 가장 높다). 서 있으면 3.4초마다 0.14초 눈을 감는다.
- 움직임 줄이기(9.7)에서는 장을 넘기지 않고 흔들림도 없다. 바라보는 쪽의 서 있기 첫 장에 선다(주민 7-6과 같은 규칙).
- 오른쪽을 보는 장은 왼쪽을 보는 장을 좌우로 뒤집은 것이다(빛의 방향도 함께 뒤집힌다).

## 화면(D-311)

- `src/ui/skin.css`가 다른 화면 CSS 뒤에 불려 겉모습만 덮어쓴다: 따뜻한 종이색 면, 위쪽의 옅은 볕, 아래쪽의 얇은 턱, 부드러운 그림자. 누르면 1 px 내려앉는다.
- 글자 대비는 바탕색(`background-color`)으로 지킨다. 글자가 놓이는 면에는 그라디언트(`background-image`)를 깔지 않는다: 대비 시험(`tests/flow/a11yTools.ts`)은 그림 위의 글자를 잴 수 없어 실패로 본다(처음에 그라디언트로 그렸다가 a11y5 시험 66개가 이 이유로 실패해서 바꿨다). 위쪽의 볕은 안쪽 그림자(`inset box-shadow`)로 그린다.
- 지역 이름패는 왼쪽에 지역색 띠가 있다(장식이고 이름은 글자로 읽는다). 단축키 표시는 작은 건반 뚜껑 모양이다.
- 아이콘은 선과 같은 색의 옅은 채움(투명도 0.2)을 더한 두 겹이다. 틀린 곳을 알리는 경고 아이콘은 선 하나 그대로다.
- 첫 안내 카드 위에 풍경 띠(`public/world/ui-intro-banner.svg`)를 둔다. 장식이라 낭독기가 읽지 않는다. 출처·권리 대장의 `img.ui.intro-banner`가 덮는다.

## 아직 이전 그림인 것(다음에 칠할 것)

- 주민(악사) 여섯과 잔치 무대의 악사: 장면이 코드로 그리는 평면 모양이다.
- 설치물 층(디딤돌, 종나무, 계단밭, 건반 다리, 물레방아, 여울목의 돌), 놀이 악기, 발견 표식: 뜻을 전하는 그림이라 색과 모양을 시험이 읽는다. 바꿀 때 시험과 함께 바꾼다.
- 강, 여울목, 다리, 울타리, 늪 웅덩이의 물: 바닥 그림의 평면 색이다.
- 악보 지도(지도 화면)와 패널 안의 그림(종나무, 건반 등).

## 사람이 확인할 것

- 새 화풍이 이 게임과 수업에 어울리는지, 아이들이 캐릭터를 자기로 느끼는지(관찰).
- 특정 게임을 닮았다는 인상이 없는지(사람의 눈).
- 회색조와 색약 시뮬레이션에서 지역과 상태가 구분되는지, 실제 기기에서 글자가 잘 읽히는지.
